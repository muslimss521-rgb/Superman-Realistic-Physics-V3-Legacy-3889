# Superman Realistic Physics V3 — GTA V Legacy 3889

Native C++ ASI project designed for ScriptHookV on GTA V Legacy 3889.

This is an original implementation. It does not include or copy proprietary source code or assets from JulioNIB, Tamed Mods, or other authors.

Implemented foundation:
- physics state and vector math
- flight / hover / boost
- superspeed
- impact-energy calculations
- strength / punch impulse
- grab / throw framework
- ground-pound framework
- heat-vision framework
- freeze-breath framework
- super-breath framework
- senses / bullet-time framework
- camera state
- costume configuration
- audio hooks
- configurable INI values

Build requirements:
- Visual Studio/MSVC x64
- ScriptHookV SDK headers and lib in `include/ScriptHookV`
- `ScriptHookV.lib`
- Windows GTA V Legacy

GitHub Actions is included as a build template. The repository must contain the ScriptHookV SDK files according to their license/redistribution terms.
