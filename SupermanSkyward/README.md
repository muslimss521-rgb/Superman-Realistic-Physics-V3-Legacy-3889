# Superman Skyward — Godot 4 prototype

A **separate** Godot 4 project inside the existing GTA V C++ repository. No GTA mod files are modified.

## Open in Godot
Import the `SupermanSkyward/project.godot` folder as a Godot 4 project. Use the Compatibility renderer on Android.

## Controls
- WASD: walk / horizontal flight
- Mouse: camera
- F: toggle flight
- Space: jump or ascend
- Ctrl: descend
- Shift while flying: boost
- Esc: release mouse

## Current scope
Procedurally generated blockout city, simple placeholder superhero character, third-person camera, collision, flight and boost, sunlight, ambient lighting, and a basic animated cape. This is **not** a finished realistic character, rigged cloth simulation, UE5 renderer, or tested Android release. Godot 4 runtime validation is still needed.
